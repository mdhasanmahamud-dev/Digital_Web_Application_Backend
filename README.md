# Digital Management Web Application — Backend

The backend of the **Digital Management Web Application** built with **Node.js, Express.js, MongoDB, and Mongoose**.

It provides REST APIs for managing **users, contacts, projects, and teams** with authentication and authorization.

## 🛠 Tech Stack

* **Node.js** - JavaScript runtime
* **Express.js** - Backend framework
* **MongoDB** - Database
* **Mongoose** - MongoDB ODM
* **JWT** - Authentication
* **Bcrypt** - Password hashing
* **Cookie Parser** - Cookie handling
* **CORS** - Cross-origin requests
* **Dotenv** - Environment variables

## ✨ Features

* User registration and login
* JWT authentication
* Password hashing with Bcrypt
* User management
* Contact management
* Project management
* Team management
* Cookie-based authentication
* REST API
* MongoDB database integration
